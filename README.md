# ЭАХС — Эрүүл ахуйн хяналтын систем

Уурхайн талбарын УХААН, ядаргаа, аюул, халдвар, **ажилтны эрүүл мэнд, хувийн ариун цэврийн хяналт**-ын бүртгэл.
Статик сайт (HTML + JS, build алхамгүй), Vercel дээр `main` салбараас автоматаар байршина.

## Үүрэг
| Үүрэг | Боломж |
|---|---|
| Ажилтан | УХААН, ядаргаа, халдварын асуумж, ариун цэврийн хяналтад "Танилцсан" гарын үсэг, аюул мэдэгдэх |
| Ахлах | Өөрийн албаны УХААН батлах, ариун цэврийн хяналтын хуудас бөглөх/хэвлэх, **ахлахын 7 хоногийн хяналтын хуудас** бөглөх/хэвлэх, өөрийн албаны аюулыг хянах, мэдэгдэл |
| Эрүүл ахуйч | Бүх самбар, ажилтан/хуваарь/аюул удирдах, мэдэгдэл, тайлан/график, QR код, Excel, ахлахын хяналтын хуудсыг харах/хэвлэх/Excel |

Аюул мэдэгдэхэд нэвтрэхгүй (нэргүй Firebase нэвтрэлт — зөвхөн аюул + зураг + их эрсдлийн мэдэгдэл үүсгэнэ).

## Нэвтрэлт (v5 — Firebase Auth)
* Хэрэглэгч бүр өөрийн Firebase Auth бүртгэлтэй: имэйл = `<sap>@eahs.local` (зохиомол, имэйл ирэхгүй), нууц үг = PIN/нууц үг. 6-аас богино хуучин PIN-д `eahs#` угтвар нэмж Firebase-д хадгална.
* Үүрэг `eahs/v2/roles/{uid}` = `{sap, role}` — дүрэм бүхэлдээ `auth.uid`-аар шалгана. Ажилтан зөвхөн өөрийн бичлэгийг уншина.
* **Шилжилт:** хуучин (PIN hash-тай) хэрэглэгч анх нэвтрэхэд Auth бүртгэл автоматаар үүсч, `roles/{uid}.proof === users/{sap}/pinHash` нөхцөлөөр үүргээ нэг удаа авна. Дараа нь `pinHash` устна. Буруу PIN → бүртгэл буцааж устгагдана.
* Эрүүл ахуйч **Ажилтнууд** хэсгээс шинэ хэрэглэгч/нууц үг үүсгэнэ (2 дахь Firebase app — өөрөө нэвтэрсэн хэвээр). Нууц үг шинэчлэхэд шинэ бүртгэл `<sap>+N@eahs.local` үүсч (`authgen/{sap}`), хуучин нь эрхгүй болно. «Нэвтрэлт» багана: Шилжсэн / Хуучин PIN / Нууц үггүй.
* Офлайн: тухайн төхөөрөмжид өмнө нэвтэрсэн хэрэглэгч локал шалгалтаар орж болно; бичлэг нь дараалалд хүлээгдэж, тухайн хэрэглэгч онлайн нэвтэрмэгц илгээгдэнэ.
* Firebase SDK ачаалагдахгүй (локал горим) бол хуучин PIN hash нэвтрэлт хэвээр.

### Firebase Console — идэвхжүүлэх дараалал (эвдрэлгүй)
1. **Authentication → Sign-in method → Email/Password → Enable** (Email link биш). **Anonymous** идэвхтэй хэвээр.
2. **Realtime Database → Rules** ← `database.rules.transition.json` (одоогийн нээлттэй дүрэм + `roles`/`authgen`/`notifs`; борлуулалт өөрчлөгдөөгүй) → Publish.
3. Аппыг байршуулах (`main` руу merge → Vercel).
4. Эрүүл ахуйч, ахлах, ажилтнууд нэг удаа нэвтэрнэ (**Ажилтнууд → Нэвтрэлт** баганаар «Шилжсэн» эсэхийг харна). Нэвтрээгүй хэрэглэгчид эрүүл ахуйч шинэ нууц үг өгнө.
5. **Rules** ← `database.rules.json` (эцсийн, хэрэглэгч бүрийн эрх) → Publish.
* Дүрмийг `python3 tools/gen-rules.py` үүсгэнэ; `database.rules.merged.json` = `database.rules.json`.
* Буцаах: Rules-д `database.rules.transition.json`-ийг дахин тавина (өгөгдөл хэвээр).

## Мэдэгдэл
* Их / Маш их эрсдэлтэй аюул, ариун цэврийн хяналтад «Ажиллахгүй» → `eahs/v2/notifs` → эрүүл ахуйч (бүгд), ахлах (өөрийн алба).
* Апп доторх мэдэгдлийн төв (уншаагүй тоо цэсэнд), хөтчийн мэдэгдэл (`Notification` + `sw.js`) — апп/таб нээлттэй үед.
* Жинхэнэ push (апп хаалттай үед): Firebase Cloud Messaging (VAPID түлхүүр, `firebase-messaging-sw.js`, токен хадгалах) + илгээгч сервер (Cloud Function — Blaze төлөвлөгөө, эсвэл Vercel function + service account нууц) шаардлагатай.

## Аюулын хяналт, тайлан, QR
* Аюул: төлөв (Шинэ / Хийгдэж буй / Шийдсэн / Хаасан), хариуцагч, гүйцэтгэх хугацаа, залруулах арга хэмжээ, түүх (`hazards/{id}/log`), хугацаа хэтэрсэн тодруулга, шүүлтүүр.
* Тайлан, график: сар/улирлаар, огнооны муж + алба шүүлтүүр, inline SVG, A4 босоо хэвлэнэ.
* QR код: алба + нэмэлт талбай (`settings/qr`) → `/?hazard&area=<нэр>` (маягт газар бөглөгдсөн нээгдэнэ). A4 хуудсанд 8 стикер, логотой. QR сан: `vendor/qrcode.js` (qrcode-generator, MIT).

## Алба (v6) — зөвхөн 2: «Оффис», «Бар»
* Сонгогч, анхны утга, самбарын хавтан, QR, тайлан/аюулын шүүлтүүр, ахлахын хамрах хүрээ, тохиргоо — бүгд `ALBA = ["Оффис","Бар"]`.
* **Хуучин өгөгдлийг дарж бичихгүй.** Харуулах/харьцуулахдаа `albaN()`: «оффис» агуулсан нэр → **Оффис**; бусад бүх нэр (Оюут баар, Манлай баар, Эрчим баар, …) → **Бар**; хоосон → хоосон.
  Аюулын газрын нэрнээс (`albaOf`): «оффис» → Оффис, «баар»/«бар» гэсэн үг → Бар, бусад → алба тодорхойгүй (бүх ахлахад харагдана).
* Дүрэм (`tools/gen-rules.py`) мөн адил хөрвүүлж харьцуулна (`NORM()`), тиймээс «Оюут баар» албатай ахлах «Бар» болон хуучин «Манлай баар» бичлэгийг засаж чадна, «Оффис»-ынхыг чадахгүй.
* Хуучин нэртэй ариун цэврийн хуудас (`2026-10-01_Оюут баар`) id-аараа нээгдэнэ, хадгалахад `alba` талбар нь өөрчлөгдөхгүй; шинэ хуудас `<огноо>_Бар` / `<огноо>_Оффис`.
* Шинэ бичлэг (УХААН, ядаргаа, халдвар, хяналтын хуудас) хөрвүүлсэн нэрээр («Бар»/«Оффис») хадгалагдана. Хэрэглэгчийг засварлахад алба нь өөрчлөгдөөгүй бол хуучин нэр хэвээр үлдэнэ.

## Ахлахын хяналтын хуудас (v7, xlsx маягт)
* Эх: «Ахлах ажилтны өдөр тутмын цэвэрлэгээ үйлчилгээний хяналт шалгалтын хуудас» (Excel). Сонгох маягт **зөвхөн 2: Оюут, Манлай** (тусдаа 2 газар; эх файлын нэгдсэн «Оюут», «Манлай» sheet). Маягт = хэсэг (чөлөөт текстгүй), алба үргэлж **Бар**.
* Ахлах (Бар) → **Хяналтын хуудас** → Оюут / Манлай + 7 хоногийн эхний өдөр (анхдагч Даваа) → гар утсанд: өдрийн товч, хэсэг бүрт «Бүгд бүрэн», мөр бүрт ✓ Бүрэн / ! Сайжруулах (+заавал биш тэмдэглэл), «Өдрийг батлах» (Шалгасан гарын үсэг). 7х1/14х1 мөр өөр өдөр «Бүрэн» болсон бол саарал.
* Эрүүл ахуйч → **Ахлахын хяналт** → бүх хуудас, зөвхөн харах, Хэвлэх, Excel; **Excel татах** хуудсанд «Ахлахын хяналтын хуудас».
* Хуучин (v6) 6 маягтын (Зөөгч, HK, Туслах, Бармен, Сервис, А.Бармен) бичлэг байвал «хуучин маягт» гэж харагдана — харах/хэвлэх л боломжтой; сонголт, шүүлтүүр, Excel-д орохгүй, дүрэм засахыг хориглоно (эрүүл ахуйч устгаж болно).
* Хэвлэх: эх xlsx-ийн байршил (Times New Roman, лого, «Баталсан» мөр, #A9D08E толгой, #FFFF00 огноо, #92D050 хэсэг, #E2EFDA давтамж, «Шалгасан гарын үсэг»), A4 хэвтээ, толгой хуудас бүрт. Excel: эх файлтай ижил бүтэц.
* Өгөгдөл: `eahs/v2/svcheck/{oyut|manlai}_{Даваа}_{Оюут|Манлай}` = `{tpl,start,heseg,alba:"Бар",inspector,createdBy,createdBySap,_u,updatedBy, cells/{мөр}/{d0..d6}: ok|imp, notes/{мөр}/{d0..d6}, sign/{d0..d6}: {by,sap,at}}` — дарах бүрт зөвхөн тухайн нүдний замыг бичнэ.
* Дүрэм: уншина — эрүүл ахуйч + ахлах; бичнэ — эрүүл ахуйч, Бар албаны ахлах (устгахгүй); `tpl ∈ {oyut, manlai}`, `heseg` маягттай тохирно, `alba === "Бар"`, огноо, нүдний утга/түлхүүр, тэмдэглэлийн урт шалгана.
* Хуучин нэрээр хадгалсан ариун цэврийн хуудас жагсаалт/засварт «Бар (Оюут баар)» гэж жижиг тайлбартай харагдана.

## Ариун цэврийн хяналт
* Эрүүл ахуйч / Ахлах → **Ариун цэвэр** → огноо + алба → хуудас нээх.
* Тухайн өдөр хуваарьтай ажилтнууд автоматаар нэмэгдэнэ (ээлжийн 1-р өдрөөс 2 өдөрт 1 удаа "Бүртгэх өдөр").
* Нүд дарж: хоосон → √ → X. Аль нэг X бол мөр улаан, "Ажиллахгүй".
* **Хэвлэх** — цаасан маягттай ижил A4 хэвтээ хуудас (18 мөр, Анхаарах, Шалгасан). Excel-д хуудас бүр тусдаа sheet.

## Өгөгдөл
* Firebase Realtime DB `eahs/v2/<цуглуулга>/<id>` — бичлэг/талбар тус бүрээр `update()` (бүх массивыг дарж бичихгүй).
* Офлайн үед localStorage (`eahs2_*`) + хүлээгдэж буй бичлэгийн дараалал (`eahs2_pending`) — холбогдмогц илгээнэ.
* Аюулын зураг `eahs/v2/photos/<id>` тусдаа (жагсаалт хөнгөн).
* Нууц үгийг Firebase Auth хадгална (шилжээгүй хэрэглэгчид түр SHA-256 `pinHash`); сесст нууц үг хадгалахгүй.
* Хуучин `eahs/eahs_*` массивууд анх нээгдэхэд нэг удаа `v2` руу хуулагдана (хуучныг устгахгүй).
* Аюулгүй байдлын дүрэм: `database.rules.json` (эцсийн) / `database.rules.transition.json` (шилжилт), `database.rules.merged.json` (= `database.rules.json`). Firebase төсөл `borluulalt-f9d70`-ийг борлуулалтын апп (`borluulalt/` зангилаа) хамт ашигладаг тул **зөвхөн нэгтгэсэн файлыг** тавина — eahs-ийн дүрэм дангаараа борлуулалтын аппыг зогсооно.

## Дизайны систем (v4)
- Өнгө «Ерөө говь» ХХК-ийн логооос: хаан хөх `--brand #1747C8` (үндсэн), улбар шар `--accent #F05A12` (онцлох, «хийх» төлөв), нарны шар `--sun` (зөвхөн чимэглэл). Ногоон зөвхөн «хангасан» төлөвт. Бүх текст WCAG AA (≥4.5:1).
- Фонт: Inter (кирилл + Ө/Ү), `fonts/`-д өөрөө байршуулсан — офлайн ажиллана.
- Дүрс: `ICONS` / `ic()` (inline SVG), гадны сан байхгүй.
- Хэвлэх маягтууд (`.sheet`, `.ppage`, OT-03) системээс тусдаа — хэвлэх үр дүн өөрчлөгдөөгүй (PDF пиксел харьцуулалтаар шалгасан).
